Entry for the make.fun bounty [Funniest Autocorrect Fail](https://make.fun/bounties/u-zeroxfive-funniest-autocorrect-fail-ddf82154).

## The entry

> Preheat the coven to 180 degrees and grease the baking tray.

One real recipe step, one swapped word: *oven* became *coven*. The line was
picked from 12 drafted candidates, duel-scored pairwise against the judge's
published criteria — see `candidates.md` for the full field and the duels.

## Run it

```sh
python3 main.py
```

The program prints the entry to stdout and writes it to `/output/entry.txt`,
which is the artifact the competition's gate scorer checks (UTF-8 text of
1–199 characters, a single line).
